This folder contains the visual resources and supporting files used in **Sesión 04 — Introducción a PHP: Programación del Lado del Servidor**.

## 📂 Purpose

The `Assets` directory is used to organize visual evidence and resources related to the development and testing of the PHP project.

These resources may include:

- Screenshots of the PHP application running locally.
- Screenshots of XAMPP and Apache.
- Form validation examples.
- Final presentation card results.
- Images used in the main `README.md`.

---

## 🐘 Session Project

The main project for this session is a **Dynamic Presentation Card Generator** developed with:

- PHP
- HTML5
- CSS3
- XAMPP / Apache

The application receives information from a form, validates the data on the server, and dynamically generates a styled presentation card.
