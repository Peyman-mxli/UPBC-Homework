# Tarea 1.2 — Identificación y Formulación del Problema

## Introducción

La identificación y formulación del problema constituye una de las etapas más importantes de un proyecto de investigación. Antes de recopilar datos o proponer soluciones, es necesario establecer con claridad qué situación se estudiará, por qué es relevante y qué relación existe entre los elementos que intervienen.

En este tema se analizan los conceptos de variables, objetivo general, objetivos específicos e hipótesis, y posteriormente se aplican para plantear un problema de investigación de forma ordenada y coherente.

---

## A. Conceptos fundamentales

### Variable

Una variable es una característica, condición o factor que puede cambiar, tomar diferentes valores o ser medido dentro de una investigación.

Las variables permiten estudiar relaciones entre fenómenos y comprobar si un cambio en un factor se asocia con cambios en otro.

### Variable independiente

Es el factor que se considera causa, condición o elemento que puede influir sobre otra variable.

### Variable dependiente

Es el efecto, resultado o respuesta que se observa y que puede cambiar en función de la variable independiente.

---

## Objetivo general

El objetivo general expresa el propósito principal de la investigación. Indica de manera amplia qué se pretende lograr al finalizar el estudio.

Debe redactarse con claridad y normalmente inicia con un verbo en infinitivo, por ejemplo: analizar, determinar, evaluar, identificar, comparar o diseñar.

---

## Objetivos específicos

Los objetivos específicos desglosan el objetivo general en acciones más concretas y ordenadas.

Deben ser claros, alcanzables, medibles y estar directamente relacionados con el problema de investigación.

---

## Hipótesis

La hipótesis es una respuesta provisional o explicación anticipada al problema de investigación.

Su función es establecer una posible relación entre las variables que posteriormente puede ser analizada o comprobada mediante la recopilación y el análisis de datos.

---

# B. Planteamiento de un problema de investigación

Para formular correctamente un problema de investigación se recomienda seguir una secuencia lógica:

1. Identificar una situación, necesidad, dificultad o fenómeno que pueda investigarse.
2. Delimitar el problema indicando población, contexto, alcance y condiciones relevantes.
3. Formular una pregunta de investigación clara.
4. Establecer un objetivo general relacionado directamente con la pregunta.
5. Proponer objetivos específicos que permitan alcanzar el objetivo general.
6. Construir una hipótesis coherente con el problema.
7. Identificar las variables involucradas en la hipótesis.

Un buen planteamiento debe ser claro, relevante, viable y medible.

---

# Ejemplo práctico

## Tema

**Influencia del uso del celular en el rendimiento académico de estudiantes universitarios.**

## Problema de investigación

**¿Cómo influye el uso excesivo del celular en el rendimiento académico de los estudiantes universitarios?**

Esta pregunta permite relacionar dos elementos medibles: el uso del celular y el rendimiento académico.

## Objetivo general

**Analizar la influencia del uso del celular en el rendimiento académico de los estudiantes universitarios.**

## Objetivos específicos

1. Identificar el tiempo promedio de uso del celular entre los estudiantes.
2. Describir el rendimiento académico de los estudiantes participantes.
3. Identificar los principales fines para los cuales se utiliza el celular.
4. Relacionar el tiempo y tipo de uso del celular con el desempeño académico.

## Hipótesis

**A mayor uso del celular con fines no académicos, menor será el rendimiento académico de los estudiantes universitarios.**

## Variables

**Variable independiente:** uso del celular.

Puede medirse mediante indicadores como:

- Horas de uso por día.
- Frecuencia de uso.
- Uso de redes sociales.
- Uso recreativo.
- Uso académico.

**Variable dependiente:** rendimiento académico.

Puede medirse mediante indicadores como:

- Promedio de calificaciones.
- Cumplimiento de tareas.
- Participación académica.
- Resultados de evaluaciones.

---

# Relación entre los elementos

```text
Problema de investigación
          ↓
Pregunta de investigación
          ↓
Objetivo general
          ↓
Objetivos específicos
          ↓
Hipótesis
          ↓
Variables
          ↓
Recopilación y análisis de datos
          ↓
Conclusiones
```

La coherencia entre todos estos elementos es fundamental. El objetivo debe responder al problema, los objetivos específicos deben apoyar al objetivo general y la hipótesis debe relacionar claramente las variables que se desean estudiar.

# Práctica

## Ejercicio

Seleccionar una situación real relacionada con el ámbito universitario y realizar lo siguiente:

1. Escribir el problema de investigación.
2. Formular la pregunta principal.
3. Redactar un objetivo general.
4. Proponer tres objetivos específicos.
5. Formular una hipótesis.
6. Identificar la variable independiente.
7. Identificar la variable dependiente.

Esta práctica permite aplicar directamente los conceptos estudiados y comprobar si existe coherencia entre problema, objetivos, hipótesis y variables.

---

# Resumen

La identificación y formulación del problema orienta todo el proceso de investigación. Las variables permiten representar los factores que serán observados o medidos; el objetivo general define la meta principal; los objetivos específicos establecen las acciones necesarias; y la hipótesis propone una explicación o respuesta que puede comprobarse mediante datos.

Un planteamiento adecuado permite desarrollar proyectos más claros, organizados y metodológicamente coherentes.

---

# Conclusión

Comprender cómo se formula un problema de investigación es fundamental para desarrollar un proyecto integrador con bases sólidas. No basta con elegir un tema; es necesario delimitarlo, convertirlo en una pregunta investigable y establecer objetivos que permitan responderla.

La hipótesis y las variables proporcionan una estructura que facilita la recopilación y el análisis de información. Cuando problema, objetivos, hipótesis y variables mantienen una relación lógica, la investigación puede desarrollarse de manera más ordenada, medible y útil para la toma de decisiones.

# Glosario

| Término | Definición |
|---|---|
| Problema de investigación | Situación o fenómeno que requiere ser estudiado mediante un proceso sistemático. |
| Variable | Característica o factor que puede cambiar y ser medido. |
| Variable independiente | Factor que puede influir sobre otra variable. |
| Variable dependiente | Resultado o efecto que se observa. |
| Objetivo general | Propósito principal de la investigación. |
| Objetivo específico | Acción concreta que ayuda a cumplir el objetivo general. |
| Hipótesis | Respuesta provisional que relaciona variables y puede comprobarse. |
| Delimitación | Definición del alcance, población, contexto y límites del estudio. |
