# Instrucciones para la calculadora COCOMO II

Herramienta: https://softwarecost.org/tools/COCOMO/

## Tamaño de software

| Campo | Configuración |
| --- | --- |
| Sizing Method | Source Lines of Code |
| New SLOC | **35000** |
| Reused SLOC / Modified SLOC | **0 / 0** |
| Maintenance | Off |
| Labor Rate | Vacío, salvo que se dé una tarifa |

## Scale Drivers

| Campo | Base | Mejora |
| --- | --- | --- |
| Precedentedness (PREC) | Low | Low |
| Development Flexibility (FLEX) | Low | Low |
| Architecture / Risk Resolution (RESL) | **Low** | **High** |
| Team Cohesion (TEAM) | Nominal | Nominal |
| Process Maturity (PMAT) | Low | Low |

## Cost Drivers

| Campo | Base | Mejora |
| --- | --- | --- |
| Time Constraint (TIME) | High | High |
| Storage Constraint (STOR) | Nominal | Nominal |
| Platform Volatility (PVOL) | High | High |
| Platform Experience (PEXP/PLEX) | **Low** | **High** |
| Use of Software Tools (TOOL) | Nominal | Nominal |
| Todos los demás (incluye SCED) | Nominal | Nominal |
