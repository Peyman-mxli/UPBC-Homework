# University Access Control System (UACS)

## Proyecto Integrador

Este folder contiene la documentación académica y técnica relacionada con el proyecto integrador **University Access Control System (UACS)** desarrollado en la Universidad Politécnica de Baja California.

El proyecto propone el desarrollo de un sistema digital para registrar, consultar y monitorear las entradas y salidas de estudiantes, docentes y personal administrativo dentro del campus universitario.

## Objetivo del proyecto

Diseñar e implementar una solución tecnológica para mejorar el control de acceso universitario mediante autenticación, registro digital de entradas y salidas, almacenamiento de datos, historial de movimientos y generación de reportes administrativos.
